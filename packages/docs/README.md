# 📚 Sentei-CSS Documentation Web

Sitio web oficial de documentación y playground de Sentei CSS, construido con Astro.

## 🚀 Desarrollo Local

Para trabajar únicamente en el sitio de documentación desde esta carpeta:

```bash
# Iniciar servidor de desarrollo
pnpm dev

# Generar build de producción (salida en dist/)
pnpm build

# Vista previa del build local
pnpm preview
```

> **Nota:** Para que los estilos de la librería se reflejen correctamente durante el desarrollo de la web, asegúrate de haber ejecutado primero 'pnpm build:css' desde la raíz del monorepo.
